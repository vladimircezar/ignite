# Ignite landing page

A buildless static landing page for Ignite, a Christian men's brotherhood focused on consistent fellowship, formation, and faithful support.

## Local preview

Run a static server from this directory and serve `dist/`:

```sh
python3 -m http.server 4173 --directory dist
```

The page contains no external runtime dependencies. The final call-to-action prepares a note for visitors to copy or share with an Ignite organizer, so no contact address or unapproved backend is invented.
